# Instagram Login Clone - School Project

## How to Run Locally
```
python server.py
```
Then open http://localhost:3000 in your browser.

## Admin Panel
Go to http://localhost:3000/admin to see all stored usernames and passwords.

## How to Deploy on Render.com (FREE)
1. Create a GitHub account (if you don't have one)
2. Push this project to a GitHub repository
3. Go to https://render.com and sign up with GitHub
4. Click "New" → "Web Service"
5. Connect your GitHub repo
6. Set:
   - **Build Command**: (leave empty)
   - **Start Command**: `python server.py`
7. Click "Create Web Service"
8. Your site will be live at a URL like: https://your-project.onrender.com
9. Admin panel: https://your-project.onrender.com/admin
